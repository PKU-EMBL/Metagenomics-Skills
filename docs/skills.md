# Skills

All 11 skills in Metagenomics Skills.

## Install

Claude Code:

```text
/plugin marketplace add PKU-EMBL/Metagenomics-Skills
/plugin install metagenomics@metagenomics-skills
```

Other platforms: [multi-platform.md](multi-platform.md).

Categories below organize skills for reference; they are not separate installs.

---

## Analysis tools (5)

| Skill | Purpose |
|-------|---------|
| `preprocessing` | fastp QC and KneadData host depletion |
| `read-based` | MetaPhlAn4 / HUMAnN4 / Kraken2 profiling |
| `gene-catalogue` | Assembly, ORF clustering, quantification, annotation |
| `mag-classical` | MetaWRAP-style MAG catalogues |
| `basalt` | PKU-EMBL BASALT / BASALT-Air refined MAG recovery |
